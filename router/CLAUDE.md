# Claude repository instructions

Open and read `AGENTS.md` in full before installing, configuring, or extending
this repository. It is the canonical instruction file for both Codex and
Claude-based agents, including the procedures for adding local curated models,
shipping repository-wide model support, protecting credentials, validating
native subagents, and preserving user configuration.

Do not duplicate or weaken those rules here. Update `AGENTS.md` when the shared
workflow changes so the two agent families follow one source of truth.
